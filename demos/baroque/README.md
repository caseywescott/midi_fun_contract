# Long Baroque Cadential Improvisation Demos

Generated by:

```bash
./scripts/generate_baroque_demo_midis.sh
```

The demos are exported from `src/tests/midi_2_cairo_print.cairo` in the same parser-format style
as the other MIDI showcases, then converted with `typescript/src/simpleMidiConverter.ts`.

| File | Focus |
|------|-------|
| `05_melody_transform_cadence_tour.mid` | Same module tour as `01`, plus anchor-safe scaffold transforms (`develop_scaffold_melody`) and passing-tone filler on stable beats (~2.3 min) |
| `01_mixed_module_tour.mid` | Broad tour: French/brise cadence, fauxbourdon 7-6, circle/ascending fifths, scalar minor cadences, Romanesca, and cadenza doppia (~2.3 min) |
| `02_sequence_modulation_etude.mid` | Sequence-heavy study with fauxbourdon, circle-of-fifths, ascending fifths, Romanesca, and repeated cadenza doppia modulation (~3 min) |
| `03_minor_scalar_cadences.mid` | Natural/harmonic minor scalar descents over 3-4-5-1 and 4-2-5-1 cadence basses (~2.5 min) |
| `04_cadential_brise_study.mid` | Cadential family focus: 4-3, 3-4-5-1 brise, French long-five, scalar descents (~2 min) |

Channels:

- `0`: ornamented upper line / brise figures
- `1`: bass schema
- `2`: alto fill
- `3`: tenor fill
