# Transformation Library MIDI Demos

Generated by `./scripts/generate_transform_demo_midis.sh`.

## How to listen

Each file is a series of **A/B comparisons**:

| Channel | Role |
|---------|------|
| **0** | Source cell — C major pentatonic degrees `[0,2,4,5,7]` (C-D-E-G-A) |
| **1** | Transformed result |
| **9** | Section marker — short low C ping before each pair |

Within each section you hear: **source → pause → result → pause → next section**.

Tempo: 120 BPM (500000 µs/quarter). Note grid: 3 time-units per note (~dotted-8th feel).

| `05_pipeline.mid` | Multi-plane pipeline (invert+rotate pitches, rotate+augment lengths, velocity table) |

## Regenerate

```bash
cd midi_fun_contract
chmod +x scripts/generate_transform_demo_midis.sh
./scripts/generate_transform_demo_midis.sh
```

Open in any DAW; solo channels 0 and 1 to compare, or watch channel 9 markers in the piano roll to jump between transforms.
