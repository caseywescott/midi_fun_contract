Beast Sound

Every Loot Survivor Beast's theme, composed from its token and its history. One URL per Beast.

/beasts/{token}/playerHTML player. Use as the NFT's animation_url.
/beasts/{token}.midMIDI file
/beasts/{token}.jsonNotes, hashes and the live stats used

{token}: a mainnet token number or a Beasts V3 token ID. Options: ?engine=1|2, ?network=sepolia|mainnet, ?patch=chip_tri_lead, ?drums=0 (drums are on by default).

Example: /beasts/52918/player · /beasts/52918.json
